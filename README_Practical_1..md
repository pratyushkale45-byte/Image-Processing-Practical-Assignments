# Image Processing Lab – Lab 1 & Lab 2

**Course:** Image Processing using Python and OpenCV

## Overview

This assignment is a practical introduction to image processing with Python. It uses OpenCV, Pillow, NumPy, and Matplotlib to read, inspect, transform, display, and compare digital images.

The work is organized as a Jupyter Notebook (`IPP Assisngment 2.ipynb`) containing ten questions.

## Assignment Tasks

1. **Read and display an image** – Load `flower.jpg` with OpenCV and display it with the title “Original Image”.
2. **Inspect image properties** – Print the height, width, number of channels, data type, and full shape of `scene.jpg`.
3. **Convert to grayscale** – Convert a colour image to grayscale and save it as `output_gray.jpg`.
4. **Open an image with Pillow** – Load and display an image using the Pillow library.
5. **Resize an image** – Reduce an image to 50% of its original width and height.
6. **Crop an image** – Extract and display the central 200 × 200 pixel region.
7. **Rotate an image** – Rotate an image 90 degrees clockwise using OpenCV.
8. **Flip an image** – Flip `car.jpg` horizontally (left to right).
9. **Convert RGB to HSV** – Convert an image to HSV colour space and display the Hue, Saturation, and Value channels separately.
10. **Calculate Mean Squared Error (MSE)** – Compare two grayscale images using MSE. The notebook resizes the second image to match the first before calculating the value.

## Technologies and Libraries

- **Python 3** – Programming language
- **OpenCV (`cv2`)** – Image loading, colour conversion, resizing, cropping, rotation, and flipping
- **NumPy** – Array operations and MSE calculation
- **Matplotlib** – Displaying images and image channels
- **Pillow (`PIL`)** – Opening and displaying images
- **Jupyter Notebook** – Running the assignment interactively
